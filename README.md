# SneakerShop 👟

Полнофункциональный интернет-магазин оригинальных кроссовок и streetwear с интеграцией **Firebase Firestore** и **Authentication**, мультиязычностью (KK / RU / EN) и полноценной панелью администратора.

## 🛠 Стек технологий

- **Frontend:** Vanilla HTML5, CSS3 (адаптивный дизайн, тёмная тема, flexbox/grid), Vanilla JavaScript (ES6+ модули).
- **Библиотеки:** Splide.js (слайдер на главной).
- **Backend / Cloud Services:** 
  - **Firebase Authentication** — регистрация, вход, сброс пароля.
  - **Firebase Firestore** — облачная NoSQL база данных с real-time слушателями (`onSnapshot`).
  - **Firebase Security Rules** — правила разграничения доступа для пользователей (`user`) и администраторов (`admin`).
  - **Firebase Hosting** — хостинг статического веб-приложения.

## ✨ Основной функционал

### 1. Каталог товаров (`index.html`)
- Интерактивный hero-слайдер избранных коллекций.
- Фильтрация по категориям (`running`, `lifestyle`, `basketball`).
- Фильтрация по наличию в городах (Алматы / Астана / Все магазины).
- Сортировка по новизне и цене в тенге (**KZT**).
- Живой поиск по названию модели и бренду.
- Пагинация (кнопка «Показать ещё»).
- Карточки товаров с индикацией наличия на складах.

### 2. Страница товара (`pages/product.html`)
- Галерея изображений товара.
- Выбор размера (EU размерная сетка).
- Real-time отслеживание складских остатков по городам.
- Добавление в корзину с синхронизацией.
- Блок отзывов с оценками и формой отправки.
- Рекомендательный блок похожих моделей.

### 3. Корзина и заказ (`pages/cart.html`)
- Изменение количества и удаление товаров.
- Выбор города получения (Алматы / Астана).
- Расчёт итоговой суммы в **KZT**.
- Оформление заказа с сохранением в Firestore (`orders`).

### 4. Личный кабинет (`pages/profile.html`)
- Авторизация, регистрация и восстановление пароля по Email.
- История заказов пользователя в реальном времени со статусами (`Ожидает`, `Подтверждён`, `Отправлен`, `Доставлен`, `Отменён`).
- Раздел «Мои отзывы» с возможностью удаления.
- Редактирование личных данных и предпочтительного города.

### 5. Панель управления (`pages/admin.html`)
> Доступна пользователям с ролью `role: "admin"`.
- **Товары (CRUD):** создание новых товаров, редактирование цен/остатков/размеров, удаление.
- **Заказы:** просмотр всех заказов клиентов и обновление их статуса в real-time.
- **Пользователи:** список зарегистрированных пользователей и назначение ролей (`user` / `admin`).
- **Модерация:** модерация и удаление отзывов.
- **Статистика:** подсчёт общего числа товаров, заказов, пользователей, отзывов и общей выручки (Revenue в **KZT**).

### 6. Мультиязычность
- Переключатель языков: Казахский (`KK`), Русский (`RU`), Английский (`EN`).
- Сохранение выбранного языка в `localStorage`.

## 🚀 Запуск проекта локально

Проект работает на чистых ES-модулях и не требует сборки.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/onipchenko/sneakershop.git
   cd sneakershop
   ```

2. Запустите любой локальный HTTP-сервер, например:
   ```bash
   npx serve .
   # или
   python -m http.server 8000
   ```
   Откройте [http://localhost:8000](http://localhost:8000) в браузере.

## 📦 Заполнение базы тестовыми данными

В проекте есть скрипт `seed.js`:
```bash
npm install
# Поместите ключ сервисного аккаунта serviceAccountKey.json в корень проекта
node seed.js
```
*(Файл `serviceAccountKey.json` защищён и исключён через `.gitignore`)*.
